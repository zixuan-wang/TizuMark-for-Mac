# ⌘Q 退出应用实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 ⌘Q 正常退出 TizuMark，并让系统菜单「Quit TizuMark」也走同一套带未保存保护的退出流程。

**Architecture:** 前端在全局快捷键表中固定注册 ⌘Q → `handleAppClose('quit')`（跳过关闭行为询问、保留未保存提示）；Rust 侧用自定义应用菜单替换 Tauri 默认菜单，仅把 Quit 换成普通菜单项 `quit-app`，点击后 emit `quit-requested`，前端走同一函数。两侧共用 `_closeInProgress` 重入保护，避免按键与菜单同时触发。

**Tech Stack:** 原生 JS（mixin 架构）、Tauri 2 / Rust 菜单 API、jsdom + node:test。

**Spec:** `docs/superpowers/specs/2026-10-31-cmdq-quit-design.md`

## Global Constraints

- 本仓库为 macOS-only；不要引入 Windows 分支或平台判断。
- **不自动 commit / push**（CLAUDE.md 红线）。每个任务以「运行相关测试通过」收尾，提交等待用户明确指示。
- 只跑与改动相关的测试，不跑全量 `npm test`。
- 不得用 `tauri-plugin-global-shortcut` 注册 ⌘Q（会全局抢键，影响其他应用）。
- Rust 菜单复刻 Tauri 默认结构，仅替换 Quit 项；不得使用 `PredefinedMenuItem::quit`。
- 所有退出路径最终仍走 `quit_app` / `exit_app`（清理托盘图标）。

## Review Focus

1. **重复触发**：⌘Q 按键与菜单事件可能同时到达 → 必须只弹一次保存框（测试：Task 1 重入保护用例）。
2. **未保存后取消**：弹保存框点「取消」→ 应用继续运行，再次 ⌘Q 仍能触发（测试：Task 1 重入标记复位用例）。
3. **托盘隐藏时点菜单退出**：窗口处于隐藏状态，必须先显示窗口再弹对话框（测试：Task 3 静态顺序断言 + 真机验收）。
4. **用户占用 ⌘Q**：录制其他动作到 ⌘Q 必须被拒绝；旧配置里已占用 ⌘Q 的绑定被固定键位覆盖（测试：Task 2 冲突用例）。
5. **方案切换**：切到 vscode/typora/sublime 或自定义后 ⌘Q 仍可用（测试：Task 2 方案切换用例）。

// ⌘Q 退出应用：
// 1. 固定注册在全局派发表（不随方案/自定义变动）
// 2. 编辑器有焦点 / 无焦点都派发，且 preventDefault
// 3. handleAppClose('quit') 跳过「关闭窗口时」询问
// 4. 重入保护：并发触发只弹一次保存框；取消后可再次触发
const test = require('node:test');
const assert = require('node:assert');
const { buildEnv, cleanup, waitForEditor } = require('./helpers/app-env.cjs');

function pressCmdQ(w, target) {
  const evt = new w.KeyboardEvent('keydown', {
    key: 'q', code: 'KeyQ', keyCode: 81, which: 81,
    metaKey: true, bubbles: true, cancelable: true,
  });
  target.dispatchEvent(evt);
  return evt;
}

async function ready() {
  const { w } = await buildEnv({ captureInitErr: true });
  const ed = await waitForEditor(w);
  for (const t of ed.tabs) t.savedContent = t.content;
  return { w, ed };
}

test('⌘Q：固定注册在全局派发表，编辑器聚焦时派发一次', async () => {
  const { w, ed } = await ready();
  try {
    assert.strictEqual(typeof ed.globalShortcutLookup['Ctrl+Q'], 'function');
    let calls = 0; let arg = null;
    ed.handleAppClose = (a) => { calls++; arg = a; };
    ed.cm.focus();
    const inner = ed.cm.getWrapperElement().querySelector('.CodeMirror-code') || ed.cm.getWrapperElement();
    const evt = pressCmdQ(w, inner);
    assert.strictEqual(calls, 1, '应派发一次 handleAppClose');
    assert.strictEqual(arg, 'quit', '应传入 quit');
    assert.ok(evt.defaultPrevented, '⌘Q 应被 preventDefault');
  } finally { cleanup(w); }
});

test('⌘Q：焦点不在编辑器时同样派发', async () => {
  const { w, ed } = await ready();
  try {
    let calls = 0;
    ed.handleAppClose = () => { calls++; };
    const evt = pressCmdQ(w, w.document.body);
    assert.strictEqual(calls, 1);
    assert.ok(evt.defaultPrevented);
  } finally { cleanup(w); }
});

test('handleAppClose("quit")：跳过关闭行为询问，无修改时直接 quitApp', async () => {
  const { w, ed } = await ready();
  try {
    let asked = 0;
    ed._resolveCloseAction = async () => { asked++; return 'minimize'; };
    let quitCalls = 0;
    w.TauriApi.quitApp = async () => { quitCalls++; };
    ed.saveSession = () => {};
    await ed.handleAppClose('quit');
    assert.strictEqual(asked, 0, '不应弹「关闭窗口时」询问');
    assert.strictEqual(quitCalls, 1, '应调用 quitApp');
  } finally { cleanup(w); }
});

test('重入保护：并发触发只弹一次保存框，取消后可再次触发', async () => {
  const { w, ed } = await ready();
  try {
    ed.tabs[0].content = 'changed';
    let dialogCalls = 0; let resolveDialog;
    ed.showSaveDialog = () => {
      dialogCalls++;
      return new Promise((r) => { resolveDialog = r; });
    };
    let quitCalls = 0;
    w.TauriApi.quitApp = async () => { quitCalls++; };
    const p1 = ed.handleAppClose('quit');
    const p2 = ed.handleAppClose('quit');
    assert.strictEqual(dialogCalls, 1, '并发触发只弹一次');
    resolveDialog('cancel');
    await Promise.all([p1, p2]);
    assert.strictEqual(quitCalls, 0, '取消不应退出');
    for (const t of ed.tabs) t.savedContent = t.content;
    ed.showSaveDialog = () => { dialogCalls++; return Promise.resolve('discard'); };
    ed.saveSession = () => {};
    await ed.handleAppClose('quit');
    assert.strictEqual(quitCalls, 1, '重入标记复位后可再次退出');
  } finally { cleanup(w); }
});

        if (this._closeInProgress) return; // 按键与菜单可能同时触发，只执行一次
        this._closeInProgress = true;
        try {
          // ……原有未保存文档处理逻辑保持不变……
          const action = forceAction || await this._resolveCloseAction();
          if (!action) return; // 用户在弹框点了取消（不清会话）
          // ……原有 quit / 非 quit 分支保持不变……
        } catch (error) {
          // ……原有 catch 保持不变……
        } finally {
          this._closeInProgress = false;
        }
      },

新增函数（放在 `build_tray` 附近）：

```rust
// 应用菜单：复刻 Tauri 默认 macOS 菜单结构，仅把 Quit 换成普通菜单项。
// 背景：PredefinedMenuItem::quit 走 terminate:，直接杀进程，绕过前端保存提示、
// 会话保存与托盘图标清理。自定义项点击后 emit quit-requested，由前端统一退出。
fn build_app_menu(app: &tauri::AppHandle) -> tauri::Result<Menu<tauri::Wry>> {
    let pkg_info = app.package_info();
    let config = app.config();
    let about_metadata = AboutMetadata {
        name: Some(pkg_info.name.clone()),
        version: Some(pkg_info.version.to_string()),
        copyright: config.bundle.copyright.clone(),
        authors: config.bundle.publisher.clone().map(|p| vec![p]),
        ..Default::default()
    };

    let quit = MenuItem::with_id(
        app,
        "quit-app",
        format!("Quit {}", pkg_info.name),
        true,
        Some("CmdOrCtrl+Q"),
    )?;

    let app_menu = Submenu::with_items(app, pkg_info.name.clone(), true, &[
        &PredefinedMenuItem::about(app, None, Some(about_metadata))?,
        &PredefinedMenuItem::separator(app)?,
        &PredefinedMenuItem::services(app, None)?,
        &PredefinedMenuItem::separator(app)?,
        &PredefinedMenuItem::hide(app, None)?,
        &PredefinedMenuItem::hide_others(app, None)?,
        &PredefinedMenuItem::separator(app)?,
        &quit,
    ])?;
    let file_menu = Submenu::with_items(app, "File", true, &[
        &PredefinedMenuItem::close_window(app, None)?,
    ])?;
    let edit_menu = Submenu::with_items(app, "Edit", true, &[
        &PredefinedMenuItem::undo(app, None)?,
        &PredefinedMenuItem::redo(app, None)?,
        &PredefinedMenuItem::separator(app)?,
        &PredefinedMenuItem::cut(app, None)?,
        &PredefinedMenuItem::copy(app, None)?,
        &PredefinedMenuItem::paste(app, None)?,
        &PredefinedMenuItem::select_all(app, None)?,
    ])?;
    let view_menu = Submenu::with_items(app, "View", true, &[
        &PredefinedMenuItem::fullscreen(app, None)?,
    ])?;
    let window_menu = Submenu::with_id_and_items(
        app,
        tauri::menu::WINDOW_SUBMENU_ID,
        "Window",
        true,
        &[
            &PredefinedMenuItem::minimize(app, None)?,
            &PredefinedMenuItem::maximize(app, None)?,
            &PredefinedMenuItem::separator(app)?,
            &PredefinedMenuItem::close_window(app, None)?,
        ],
    )?;
    let help_menu = Submenu::with_id_and_items(
        app,
        tauri::menu::HELP_SUBMENU_ID,
        "Help",
        true,
        &[],
    )?;

    Menu::with_items(app, &[&app_menu, &file_menu, &edit_menu, &view_menu, &window_menu, &help_menu])
}
```
